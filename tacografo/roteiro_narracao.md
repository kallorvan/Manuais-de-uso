## audio_01.mp3 · Slide 1: Tacógrafo Digital

```text
Olá! Neste manual, você vai aprender, passo a passo, a usar o tacógrafo digital do veículo para cadastrar um novo motorista, conectar o motorista antes de iniciar a viagem e desconectar ao final da jornada. É rápido e simples. Vamos lá?
```

## audio_02.mp3 · Slide 2: Conheça o painel

```text
Antes de começar, conheça o painel. Na tela inicial aparecem a velocidade do veículo, a data e a hora, o odômetro e, no canto direito, o código do motorista conectado. Abaixo da tela ficam quatro botões. O botão Voltar retorna à tela anterior. As setas para cima e para baixo navegam pelos menus e alteram os números. E o botão OK confirma a opção escolhida.
```

## audio_03.mp3 · Slide 3: O que você vai aprender

```text
O manual está dividido em três partes. Primeiro, como cadastrar um novo motorista na lista do tacógrafo, informando o código e a habilitação. Depois, como conectar o motorista antes de iniciar a viagem. E, por fim, como desconectar o motorista ao final da jornada.
```

## audio_04.mp3 · Slide 4: Cadastrar um novo motorista

```text
Parte um: cadastrar um novo motorista. Esse procedimento é feito apenas uma vez para cada motorista que vai utilizar o veículo.
```

## audio_05.mp3 · Slide 5: Acesse o gerenciamento da lista

```text
Com o veículo parado, a partir da tela inicial, use as setas até aparecer a opção Gerenciamento da lista de motorista. Em seguida, pressione OK para entrar.
```

## audio_06.mp3 · Slide 6: Escolha Cadastrar código do motorista

```text
Dentro desse menu existem duas opções: Remover código do motorista, que exclui alguém da lista, e Cadastrar código do motorista, que inclui um novo motorista. Use as setas até a opção Cadastrar e pressione OK.
```

## audio_07.mp3 · Slide 7: Grave a informação no BVDR

```text
O tacógrafo vai perguntar se deseja gravar a informação do motorista no B V D R. Selecione a opção Sim, usando a seta para baixo, e confirme com OK.
```

## audio_08.mp3 · Slide 8: Digite o código do motorista

```text
Agora, digite o código do motorista. Ele é formado pelos primeiros dígitos do C P F do motorista: quatro ou cinco dígitos, dependendo do modelo do tacógrafo. Cada asterisco na tela representa um dígito a preencher. Use as setas para escolher o número de cada dígito e pressione OK para passar para o próximo. No exemplo, o modelo pede cinco dígitos e o C P F começa com nove nove nove nove nove, então o código é nove nove nove nove nove.
```

## audio_09.mp3 · Slide 9: Digite o número da CNH

```text
Na sequência, aparece a tela Digite a habilitação do motorista. Informe o número da C N H usando o mesmo método: as setas escolhem o número e o OK avança para o próximo dígito, até preencher o campo inteiro.
```

## audio_10.mp3 · Slide 10: Confira e confirme os dados

```text
O tacógrafo mostra o código e o número da C N H digitados. Confira com atenção. Se estiver tudo certo, selecione Sim e pressione OK. Se houver algum erro, escolha Não e digite novamente.
```

## audio_11.mp3 · Slide 11: Motorista cadastrado

```text
Pronto! A mensagem Motorista cadastrado confirma que o novo motorista já faz parte da lista do tacógrafo. Pressione Voltar até retornar à tela inicial.
```

## audio_12.mp3 · Slide 12: Conectar o motorista

```text
Parte dois: conectar o motorista. Faça isso sempre antes de iniciar a viagem, para que o tacógrafo registre a jornada no nome correto.
```

## audio_13.mp3 · Slide 13: Abra o Menu do motorista

```text
Na tela inicial, use as setas até encontrar a opção Menu do motorista e pressione OK.
```

## audio_14.mp3 · Slide 14: Selecione Conecte-se

```text
Dentro do Menu do motorista, navegue até a opção Conecte-se e pressione OK. Atenção para não confundir com a opção Viagem finalizada, que aparece logo ao lado.
```

## audio_15.mp3 · Slide 15: Escolha Lista de motoristas

```text
O tacógrafo oferece duas formas de identificação: Manual ou Lista de motoristas. Selecione a opção dois, Lista de motoristas, e pressione OK.
```

## audio_16.mp3 · Slide 16: Selecione o seu código

```text
Aparece a lista com todos os motoristas cadastrados no veículo. Use as setas até destacar o seu código e pressione OK.
```

## audio_17.mp3 · Slide 17: Confirme a conexão

```text
Confira o código e a C N H, selecione Sim e pressione OK. De volta à tela inicial, observe que o seu código agora aparece no canto direito. Isso indica que você está conectado e pronto para iniciar a viagem.
```

## audio_18.mp3 · Slide 18: Desconectar o motorista

```text
Parte três: desconectar o motorista, ao final da jornada de trabalho.
```

## audio_19.mp3 · Slide 19: Desconecte em três toques

```text
Na tela inicial, use as setas até o Menu do motorista e pressione OK. O tacógrafo pergunta: Desconectar motorista? Selecione Sim e pressione OK. A mensagem Motorista desconectado confirma que a sua jornada foi encerrada.
```

## audio_20.mp3 · Slide 20: Resumo rápido

```text
Recapitulando: para cadastrar, acesse Gerenciamento da lista, escolha Cadastrar, informe o código e a C N H e confirme. Para conectar, vá ao Menu do motorista, escolha Conecte-se, depois Lista de motoristas, selecione o seu código e confirme. Para desconectar, vá ao Menu do motorista e confirme a desconexão. Lembre-se: faça tudo com o veículo parado e sempre confira o seu código na tela inicial antes de sair. Boa viagem!
```
